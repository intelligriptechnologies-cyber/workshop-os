# S28 — Pilot, cutover, rollback, hypercare, and second tenant

Status: Approved  
Implements: R-118, R-119

## Outcome
Run measurable parallel reconciliation, controlled launch, recovery, hypercare, and repeatable no-fork onboarding.

## Acceptance criteria
- [ ] Two weeks of parallel operation meet agreed operational, stock, invoice, payment, and custody reconciliation tolerances before go/no-go.
- [ ] Rehearsed cutover and rollback have named authority, evidence, communication, and data reconciliation; four weeks hypercare tracks incidents/SLOs to exit thresholds.
- [ ] A second tenant completes the same provisioning, configuration, import, training, isolation, cutover, and acceptance playbook without a code fork.
