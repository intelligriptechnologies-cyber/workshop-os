# Deliver custom roles and aligned authorization

Status: Planned  
Implements: V12-R010, V12-R011  
Blocked by: V12-04

## Outcome

Deliver versioned custom roles, a permission catalog/tree, protected templates, and one permission vocabulary shared by navigation and API enforcement.

## Acceptance criteria

- [ ] Authorized admins can search the permission tree and create/version/archive custom roles with page and action grants.
- [ ] Protected templates cannot be weakened, renamed, archived, or deleted through UI or direct API calls.
- [ ] Changing a role produces the expected navigation/control visibility after policy refresh and the API enforces the same keys.
- [ ] Global search and exports omit denied records, identifiers, snippets, and counts.
